# Little Witch in the Woods — русский перевод

**Версия перевода:** 1.0.4

**Версия игры:** 7.4.3.0 (Steam build 26107519)

[Скачать Windows / Steam Deck](https://github.com/hexelune/little-witch-in-the-woods-ru/releases/download/v1.0.4/Little_Witch_RU_Windows_Steam_Deck_v1.0.4.zip) · [Подробная инструкция](README.html)

- Полностью вычитаны 48,124 записей; подготовлены правки 4,521 записей: естественный русский порядок слов, контекст, речь персонажей и единая терминология.
- Переведены 63 новые записи обновления: обмен рыбы на приманку, юбилейное письмо и мебель, дополнительные реплики.
- Переведены ещё 95 книжных записей, отсутствовавших в прежнем русификаторе.
- Добавлены 15 музейных реплик персонажей, отсутствовавших в прежнем переводе.
- Учтены новые условия расхода приманки. Ресурсы пересобраны на основе версии 7.4.3.0 с сохранением её игровых изменений.
- Сохранено оформление шрифтов и исправления интерфейса, включая боковые цели.
- Steam Deck: четыре прямых запуска с короткими ASCII-именами, без ошибки KDE и консольных вопросов.
- Резервная копия необязательна и содержит только заменяемые файлы. Копии разных сборок игры хранятся отдельно.
- Подробная HTML-инструкция: установка, обновление, удаление, восстановление и решение возможных проблем.

Распакуйте архив в новую папку. Windows: запустите EXE из папки Windows. Steam Deck: откройте Steam_Deck и выберите один из четырёх прямых запусков. Полная инструкция находится в README.html. Для установки требуется именно указанная сборка игры.

Пакет Switch не изменён и остаётся в [выпуске v1.0.3](https://github.com/hexelune/little-witch-in-the-woods-ru/releases/tag/v1.0.3).

Основа перевода: LWitWMod 1.4.1 — Chieftain51. Лицензия адаптированного шрифта Pangolin — SIL OFL 1.1, включена в HTML README.
