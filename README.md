# Little Witch in the Woods — русский перевод

Вычитанный русский перевод для **Windows**, **Steam Deck** и **Nintendo Switch с Atmosphère**.

**Скачать:** раздел [Releases](https://github.com/hexelune/little-witch-in-the-woods-ru/releases/latest). В одном ZIP — три русификатора и краткая инструкция `README.html`.

## Совместимость

| Платформа | Версия игры |
| --- | --- |
| Windows / Steam Deck | Steam build 25956288 |
| Nintendo Switch / Atmosphère | Обновление v131072; внутренняя версия 7.2.1.0 |

В самой игре выберите **English / Английский**. Перед установкой полностью закройте игру.

## Установка

- **Windows:** распакуйте ZIP, запустите `Windows/Русификатор_Windows.exe`, выберите папку игры и нажмите «Установить перевод».
- **Steam Deck:** в Desktop Mode распакуйте ZIP и запустите `Steam_Deck/1_Установить_перевод.desktop`. Папку `Служебные_файлы` оставьте рядом с ярлыками.
- **Switch:** скопируйте `atmosphere` из папки `Switch` в корень microSD. Итоговый путь: `atmosphere/contents/010057D02461E000/romfs/Data/`.

Проверка и удаление на Windows доступны в том же EXE, на Deck — ярлыками 2 и 3. Существующую папку `.lwitw-ru-backup` сохраняйте. На Switch перевод удаляется удалением скопированных файлов.

## Изменения относительно исходного мода

- Перевод и Pangolin встроены в ресурсы; MelonLoader не требуется.
- Убран периодический обход текста из исходного мода.
- Переработаны кальки и тяжёлые фразы; уточнены контекст, род, обращения и речь персонажей.
- Согласованы названия предметов, зелий и мест.
- По корейскому оригиналу переведены 62 цели с отсутствующим или пустым английским текстом.
- Исправлен пропуск переноса старых таблиц боковых целей в адаптацию. Переводы названий уже присутствовали у исходного автора.
- Подготовлены установщики, резервные копии и откат; для Switch отдельно вычитаны отличия её версии.

Установщики не редактируют сохранения. Для обычных сюжетных заданий новая игра не требуется.
