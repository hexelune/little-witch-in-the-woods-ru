# Little Witch in the Woods — русский перевод

**Версия перевода:** 1.0.3

**Версия игры:** 7.3.7.0 (Steam build 25956288)

**Версия игры Switch:** 7.2.1.0, обновление v131072; Title ID `010057D02461E000`.

[Скачать v1.0.3](https://github.com/hexelune/little-witch-in-the-woods-ru/releases/download/v1.0.3/Little_Witch_RU_Windows_Switch_Steam_Deck_v1.0.3.zip) · [Подробная инструкция](README.html)

- 50 адресных литературных правок: естественный порядок слов, сочетаемость, реплики и описания. Учтены контекст и все доступные языки.
- Те же изменения перенесены в нативный пакет Nintendo Switch / Atmosphère.
- Исправлена ошибка Steam Deck `No module named backup_policy` при запуске из другой папки.
- Steam Deck: четыре понятных файла запуска — установка с резервной копией, установка без неё, проверка и удаление. Одно нажатие запускает действие; дополнительного меню и консольных вопросов нет.
- Резервируются только заменяемые ресурсы; существующие оригиналы сохраняются.
- Подробный HTML README: установка, обновление, восстановление и решение проблем. Оформление Windows-установщика сохранено.

Steam Deck: распакуйте весь архив в режиме рабочего стола. В папке `Steam_Deck` откройте нужный из четырёх файлов `.desktop`; папку данных оставьте рядом.

Windows: запустите EXE из архива, проверьте папку игры и установите перевод. После установки выберите «Русский».
