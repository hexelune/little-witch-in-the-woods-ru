ПК-версия игры обновилась до 7.4.5.0. В общем архиве пакет Switch остаётся для прежней 7.2.1.0; обновления до соответствующей версии Switch в комплекте нет. Поэтому переводы и набор исправлений различаются: полная вычитка 1.0.4 и новые строки обновления относятся к Windows и Steam Deck.

**Адаптация для Switch:** при наличии актуальной версии игры для Switch любой желающий может самостоятельно адаптировать к ней перевод. Этот архив включает Switch-пакет из 1.0.3; совместимость с другими обновлениями Switch не заявляется.

Распакуйте архив в новую папку. Windows: запустите EXE в `Windows`. Steam Deck: выберите одно из четырёх прямых действий в `Steam_Deck`. Switch: скопируйте содержимое `Switch/atmosphere` в папку `atmosphere` в корне microSD, объединив каталоги. Полная пошаговая инструкция — в `README.html`.

Установите перевод поверх предыдущего: восстановление через Steam перед установкой известных файлов русификатора не требуется. Switch из 1.0.3 переустанавливать не требуется.
