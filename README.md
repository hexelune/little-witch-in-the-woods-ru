Распакуйте весь архив и закройте игру. После установки выберите **«Русский»** в игре.

## Установка

- **Windows:** откройте `Windows/Русификатор_Windows.exe`, проверьте папку игры, выберите режим резервного копирования и нажмите «Установить перевод».
- **Steam Deck:** в режиме рабочего стола откройте `Steam_Deck/1_Установить_перевод.desktop`. Держите папку `Служебные_файлы` рядом с ярлыками.
- **Switch:** скопируйте `atmosphere` из папки `Switch` в корень microSD. Итоговый путь: `atmosphere/contents/010057D02461E000/romfs/Data/`. Сначала сохраните прежние моды этой игры, если они есть.

Windows-установщик и ярлыки Deck также позволяют проверить перевод и восстановить сохранённые оригиналы. На Switch удаление выполняется удалением скопированных файлов перевода.

## Резервные копии

- По умолчанию копируются только заменяемые ресурсы; перед установкой копирование можно отключить.
- Без копий возврат к оригиналам выполняется проверкой целостности файлов в Steam.
- Уже сохранённые оригиналы в `.lwitw-ru-backup` сохраняются при обновлении.
- Поддерживаемая предыдущая редакция обновляется установкой поверх неё. Сохранения установщик не редактирует.

## Изменения 1.0.1

- Исправлены **149 записей: 60 диалоговых и 89 табличных**. Смысловые решения сверены с пятью встроенными языковыми наборами.
- Согласованы обращения в интерфейсе; исправлены «ё», пунктуация, протяжные звуки и тяжёлые повторы.
- Адаптирована пословица о цветке и согласован её повтор. Уточнены научные заметки, контекст отдельных реплик и описания леденцов.
- Переработаны три описания испытаний Дианы; русский язык ясно обозначен в меню.
- Восстановлены родные шрифты китайского, корейского и японского; кириллица подключена через отдельный Pangolin.
- У однотипных пунктов меню выровнен размер текста; четыре подписи управления сокращены вместо уменьшения шрифта.
- В Windows EXE встроена оригинальная иконка игры во всех девяти размерах.
- Добавлены выбор резервного копирования заменяемых ресурсов и аккуратная ссылка на блог автора адаптации.
