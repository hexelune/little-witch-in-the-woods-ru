  • Исправлен запуск из Dolphin/KDE при ошибке Invalid unit name or type: технические имена файлов стали короткими и состоят из ASCII. Русские названия действий сохранены.
  • Четыре файла сразу выполняют выбранное действие: установка с резервной копией, без неё, проверка или удаление. Дополнительного меню и вопросов в консоли нет.
  • Распакуйте весь новый архив в новую папку. Не копируйте ярлыки поверх старой папки: прежние файлы с длинными русскими именами не должны оставаться рядом.
  • Для уже установленного перевода этой же версии повторная установка не нужна. Проверка и удаление доступны из нового пакета.
  • Текст перевода, игровые ресурсы и Windows EXE сохранены из указанной версии перевода.

Windows

  1. Запустите Windows/Русификатор_Windows.exe.
  2. Проверьте найденную папку игры или укажите папку с LWIW.exe вручную.
  3. Выберите, сохранять ли копии заменяемых ресурсов, и нажмите «Установить перевод».
  4. Дождитесь завершения, затем запускайте игру через Steam.

Проверка и удаление перевода доступны в том же установщике. Отдельный Python и MelonLoader не требуются.

Steam Deck

  1. В режиме рабочего стола распакуйте архив на Deck.
  2. Откройте Steam_Deck/com.github.hexelune.LittleWitch.InstallBackup.desktop и разрешите выполнение, если появится такой запрос.
  3. Для установки без новых копий вместо первого файла откройте com.github.hexelune.LittleWitch.InstallNoBackup.desktop. Оба файла сразу запускают выбранное действие, без дополнительного меню и ввода в консоль.
  4. Игра ищется в библиотеках Steam автоматически, в том числе на microSD. Если найдено несколько папок или ни одной, выберите папку с LWIW.exe и LWIW_Data в открывшемся окне. Дождитесь окна с результатом.
  5. После установки вернитесь в игровой режим и запустите игру через Steam.

Ярлыки и папку Служебные_файлы держите вместе. com.github.hexelune.LittleWitch.Check.desktop проверяет целостность; com.github.hexelune.LittleWitch.Uninstall.desktop восстанавливает оригиналы из копии. Нужны Python 3 и KDialog либо Zenity. Дополнительные модули Python и MelonLoader не требуются.

Резервные копии и обновление

  • По умолчанию сохраняются только заменяемые ресурсы. В Windows режим задаётся флажком. На Deck откройте соответствующий файл установки — с копией или без неё.
  • Без резервных копий оригиналы можно вернуть проверкой целостности файлов в Steam.
  • Уже сохранённые оригиналы в .lwitw-ru-backup сохраняются при обновлении. Не удаляйте эту папку, если планируете откат через установщик.
  • Редакции 1.0.1 и 1.0.2 можно обновить новым установщиком поверх них. Распакуйте новый пакет в отдельную папку и выберите установку. Папку с имеющимися оригиналами сохраняйте. Если установлен неизвестный мод или несовместимый пакет, сначала восстановите оригиналы его установщиком либо проверкой целостности Steam.

Сохранения установщик не редактирует. Новая игра для обычных сюжетных заданий не нужна: перезапустите игру и загрузите сохранение. Уберите параметры запуска Steam, добавленные специально для MelonLoader.

Если возникла проблема

  • Deck открывает файл как текст: в Dolphin откройте свойства файла .desktop, разрешите выполнение и выберите запуск. Распаковывайте весь архив; папка Служебные_файлы должна находиться рядом.
  • Invalid unit name or type: удалите старую распаковку пакета или распакуйте этот архив в новую папку. Запускайте файл с коротким ASCII-именем из таблицы выше. Настройки KDE менять не требуется.
  • Окно не появилось: используйте режим рабочего стола SteamOS. Проверьте наличие Python 3 и KDialog/Zenity. Не переносите отдельный файл запуска и не смешивайте разные выпуски.
  • No module named backup_policy: используйте этот пакет целиком. Исправлен запуск из произвольной рабочей папки; недостающие модули из старого архива копировать не нужно.
  • Версия файлов не совпадает: Пакет рассчитан на Steam build 25956288. Восстановите файлы игры, уберите другие моды и установите пакет подходящей версии. Не обходите проверку удалением резервных копий.
  • Нет полного набора копий: восстановите оригиналы через Steam. Сам установщик не может вернуть файл, для которого не была сохранена копия. Снятие флажка или установка без новых копий уже сохранённые оригиналы не стирает.
  • Нет места или доступа: нужны место для заменяемых ресурсов и временного отката, а при установке с копией — также для оригиналов. Сохраняются только заменяемые файлы. Выбирайте папку своей библиотеки Steam; на Deck не используйте sudo.
  • Игра закрыта, а проверка процессов сообщает сбой: отдельное сообщение содержит операцию и системный код ошибки. Это не сообщение о работающей игре. При настоящем обнаружении процесса завершите игру; при ошибке проверки сохраните журнал.
  • Где журнал: на Deck — Steam_Deck/Служебные_файлы/installer-last-run.log. В Windows подробности сохраняются в локальном журнале установщика. Сохраните его до следующего запуска.
  • На экране другой язык: выберите «Русский», затем перезапустите игру. Удалите старые параметры запуска MelonLoader. После проверки целостности Steam установите перевод заново.

Что изменилось в 1.0.3

  • 50 адресных литературных правок: перестроены тяжёлые фразы и порядок слов в репликах Элли, Рубрума, Эните, Клары и других героев, а также в описаниях. Учтены соседние реплики и все доступные языки.
  • «Яблочный пирог бабушки!» → «Бабушкин яблочный пирог!»; «Сначала я так ощущала» → «Поначалу мне тоже так казалось».
  • Steam Deck: исправлен импорт backup_policy при запуске из другой папки; добавлены четыре прямых файла запуска — установка с копией, установка без неё, проверка и удаление. Дополнительного меню выбора и консольных вопросов нет.
  • Расширена HTML-инструкция. Оформление Windows-установщика сохранено.

Ранее, в 1.0.2

  • Сбой проверки процессов Windows больше не выдаётся за ошибку доступа к игровым файлам и не требует закрывать уже закрытую игру.
  • Сообщение содержит операцию Windows и системный код. Подробности сохраняются в локальном журнале установщика.
  • При сбое проверки замена ресурсов не начинается. При проверке процессов просьба закрыть игру появляется только при обнаружении её процесса.

Ранее, в 1.0.1

  • 149 исправленных записей: 60 диалоговых и 89 табличных. Смысловые решения сверены с английским, корейским, японским и обоими китайскими наборами.
  • Согласованы обращения в интерфейсе; исправлены «ё», пунктуация, протяжные звуки и тяжёлые повторы.
  • Пословица о недолговечном цветке адаптирована по-русски; её повтор в другой сцене сохранён.
  • Уточнены заметки о лунофобных растениях, реплики об обвинении Лизы и описания леденцов. Переработаны три описания испытаний Дианы.
  • Русский набор обозначен в выборе языка как «Русский».
  • Восстановлены родные шрифты китайского, корейского и японского; для кириллицы подключён отдельный Pangolin.
  • У однотипных пунктов меню выровнен размер текста. Четыре подписи управления сокращены без уменьшения шрифта: «Действие / ОК», «Сменить инструмент», «Применить предмет», «Доп. действие».
  • В Windows EXE встроена оригинальная иконка игры во всех девяти размерах.
  • В установщике появился выбор резервного копирования заменяемых ресурсов и ссылка на блог автора адаптации.

Отличия от исходного мода

  • Перевод и шрифт встроены в ресурсы; MelonLoader и его периодический обход текста не нужны.
  • Вычитаны диалоги и описания, согласованы имена и названия предметов, зелий и мест.
  • Перенесены старые таблицы боковых целей и переведены 62 цели с отсутствующим или пустым английским текстом.
  • Подготовлены установщики Windows и Steam Deck и отдельный пакет нативных ресурсов Switch.
