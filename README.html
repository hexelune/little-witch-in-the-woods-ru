Windows

  1. Запустите Windows/Русификатор_Windows.exe.
  2. Проверьте найденную папку игры. При необходимости нажмите «Выбрать…» и укажите папку с LWIW.exe.
  3. Нажмите «Установить перевод», дождитесь завершения и запустите игру через Steam.

Python и MelonLoader не требуются. Проверка и удаление перевода — кнопками в том же EXE.

Steam Deck

  1. В Desktop Mode распакуйте архив на Deck.
  2. Откройте Steam_Deck/1_Установить_перевод.desktop и подтвердите запуск. Если ярлык открывается как текст: «Свойства → Права доступа → Разрешить выполнение».
  3. Подтвердите папку игры или выберите её вручную. Дождитесь завершения.
  4. Вернитесь в Gaming Mode и запустите игру через Steam.

Ярлыки и папку Служебные_файлы держите вместе. Проверка — ярлык 2; удаление — ярлык 3.

Windows и Deck: можно установить поверх предыдущих поддерживаемых редакций перевода. Папку .lwitw-ru-backup сохраняйте. Уберите параметры запуска, добавленные специально для MelonLoader.

Nintendo Switch · Atmosphère

  1. Полностью закройте игру через HOME → X. На консоли должно быть установлено обновление v131072.
  2. Если для этой игры уже есть моды, сохраните копию её папки atmosphere/contents/010057D02461E000.
  3. Скопируйте папку atmosphere из раздела Switch в корень microSD, объединив папки.
  4. Запустите консоль с Atmosphère, затем игру. Выберите English.

Контрольный путь: SD:/atmosphere/contents/010057D02461E000/romfs/Data/resources.assets.

Удаление: уберите скопированные семь файлов перевода. Если других модов этой игры нет, можно убрать её папку 010057D02461E000 целиком.

Изменения относительно исходного мода

  • Работа без MelonLoader: тексты и Pangolin встроены в игровые ресурсы.
  • Меньше фоновой работы: убран обработчик исходного мода, обходивший текст каждые 0,25 секунды.
  • Литературная редактура: переработаны кальки и тяжёлые фразы; уточнены контекст, род, обращения и речь персонажей.
  • Единые термины: согласованы имена и названия предметов, зелий и мест. Например, «Кельма Ведьмы» → «Ведьмина лопатка».
  • Дополнены задания: по корейскому оригиналу переведены 62 цели с отсутствующим или пустым английским текстом.
  • Исправлены боковые цели: перенесены обе копии старых таблиц заданий. Это исправление пропуска нашей адаптации; переводы названий уже были у исходного автора.
  • Установка: EXE для Windows, ярлыки для Deck; проверка файлов, резервные копии и откат. Для Switch подготовлена папка Atmosphère.
  • Switch: использованы нативные ресурсы консоли; отдельно вычитаны 10 отличий её исходного текста.

Сохранения установщики не редактируют. Для обычных сюжетных заданий новая игра не нужна; после установки полностью перезапустите игру и загрузите сохранение.

Проверены ресурсы, Windows-установщик, обновление и откат. Физические Switch и Steam Deck не тестировались; замеры производительности не выполнялись. Совместимость с другими обновлениями не проверена.
